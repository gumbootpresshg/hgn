# HGN v0.60.4

## Article editor polish

- Tightened the headline / slug / excerpt card so the editor no longer wastes large vertical gaps between fields.
- Added a **Generate from article** button beside Subtitle / excerpt.
- Excerpt generation is local and deterministic: it strips article HTML and uses the opening one or two sentences as an editable starting point.
- Existing manual excerpt editing is unchanged.
- No database migration is required.
