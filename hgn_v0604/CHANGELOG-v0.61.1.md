# HGN v0.61.1 - Mobile Front Page Composition

## Changed
- Added Editorials directly to the public Opinion navigation menu.
- Rebuilt the phone homepage as a deliberately edited mobile front page rather than stacking the full desktop news column before sidebar content.
- Mobile sequence is now Top Story, Latest Headlines, Opinion, More News, Sports, Columns, Events, Reader Poll, additional local news, Community & Marketplace, and Support HGN.
- Limited the first mobile run of general news so readers reach Opinion, Sports and Columns much sooner.
- Preserved the existing desktop newspaper composition at the large breakpoint.
- Deduplicated mobile story selections across the early sections where practical.

## Database
- No Supabase migration required.
