# Deploy HGN v0.67.43

Run `supabase/v312-halloween-pumpkin-launch.sql` in the public HGN Supabase project after deploying the release. It replaces the current special-event promotion with the Pumpkin Carve-Off and reopens the existing 2026 contest only if it was left in Draft or Archived.

Then open **Admin → Pumpkin Carve-Off** and confirm the entry close date is still in the future. The public page accepts JPG, PNG or WebP photos below 12 MB. Submitted entries arrive as **Pending**; approve the first one in the same Admin page to place it in the public gallery.
