# HGN v0.67.4 — Election Guide & Site Promotion Banner

- Adds a scheduled, optional-image Front Page Site Promotion Banner for HGN editorial campaigns and special events.
- Adds an editable Election Guide in Admin → Election Guide.
- Editors can set the public title, voting information and question-submission link.
- Adds up to three (or more) forum days, with School Board and Municipal YouTube slots independently marked upcoming, live, replay or hidden.
- Editors select published HGN articles for the election coverage grid.
- Adds editable candidate/race cards while retaining the existing public candidate guide as a safe fallback until races are entered.
- Adds additive, public-HGN-only Supabase migration `v301-election-guide-and-promotion-banner.sql`.
