# HGN Public Admin Simplification - Phase 1

## Daily workflow
The public admin now centers daily staff work around two incoming queues:

1. **Inbox** (`/admin/inbox`) for correspondence where the primary action is read, reply, assign, or archive.
2. **Submissions** (`/admin/submissions`) for reader material that may become published content or a public listing.

Specialist pages remain responsible for actual review/publishing actions such as Letters, Events, Obituaries, Island Lens, Marketplace and the Visitor Guide.

## Main admin work areas
- Newsroom
- Incoming
- Community
- Audience
- Local Commerce
- Island Guide
- Platform

## Hidden from normal navigation
Older daily desks, command centres, beta/launch tools, duplicate publishing helpers, the old Content Hub, old Submission Desk, duplicate homepage controls and other historical utilities remain reachable only from `/admin/legacy-tools` for publisher review.

## Diagnostics
Submission Shield, Submission Inbox Guard, Moderation/Trust & Safety, Platform Map and App Readiness are grouped from `/admin/site-health` rather than presented as daily inboxes.

## Later Phase 2
After staff use this simplified navigation, review legacy-route usage and remove dead code only after confirming no required workflow depends on it. Foreign-project/PuckScope candidate routes should be prioritized for dependency review.
