# HGN v0.65.0 — Publisher CMS + Archive Newsstand

## Added
- Block-based Page Builder with drag-to-reorder content blocks.
- Publisher/editor Pages workspace and custom public `/pages/[slug]` pages.
- Footer editor for groups, links, visibility and external URLs.
- Archive Newsstand manager with PDF/cover uploads and publish/feature controls.
- Public virtual newsstand with featured issue, cover rack, year filter and archive search.
- Broader site search across stories, pages, events, obituaries, notices, archive editions and writers.
- Correction request choice for Online, Print newspaper or Both, plus edition/page details.

## Fixed / cleaned up
- Letters to the Editor no longer intentionally includes generic Opinion articles.
- Notices added to the default Community navigation model.
- Removed the public Accessibility Status route and footer link.
- Replaced PuckScope Terms and Privacy content with Haida Gwaii News content.
- About, Terms and Privacy can be managed from the new CMS after migration.

## Safety
- No historical content is deleted by the migration.
- Built-in managed pages cannot be deleted through the CMS API.
