# Deploy HGN v0.66.3

Run `supabase/v294-public-page-cms-expansion.sql` first in the **Public HGN Supabase** project. It is additive and only creates CMS records for existing public information pages.

Then overlay this release onto `C:\HGN\HGNSite`, preserving `.git` and `.env.local`, install dependencies and run the validation commands.
