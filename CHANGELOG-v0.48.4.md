# HGN v0.48.4 - Lead Story and Sticky Navigation Balance

## Fixed

- Reduced and capped the homepage lead headline so long titles no longer create an oversized left column.
- Narrowed the headline measure for more natural newspaper line breaks.
- Rebalanced the three-column lead layout so the headline, image, and opinion rail feel proportionate.
- Changed the lead image to a wider 16:9 presentation and prevented the image column from stretching with the headline column.
- Removed the large dead area that appeared beneath the lead image when a headline was unusually long.
- Made the sticky navigation fully opaque with a stronger lower rule and shadow so it remains visually separate from articles while scrolling.
- Slightly reduced the sticky navigation height and added a divider after the compact HGN marker.

- Updated project version to 0.48.4.
